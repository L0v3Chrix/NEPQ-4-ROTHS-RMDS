## Context

This project converts an existing comprehensive HTML training guide into a production-ready Next.js application. The original HTML file (`nepq-training-guide.html`) contains a complete NEPQ (Neuro-Emotional Persuasion Questioning) training system for teaching sales methodology around Roth conversions, RMDs, and infinite banking.

### Original File Features:
- 6 stages of NEPQ methodology with detailed questions
- Interactive psychology explanations for each question
- Flashcard practice mode with flip animations
- Quiz mode with scoring and feedback
- Mobile-responsive design
- Modern gradient-based UI

---
